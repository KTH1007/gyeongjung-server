# 경중또늦네

경의중앙선 열차가 늦으면 웹 푸시로 알려주는 PWA입니다. 지금 얼마나 늦는지뿐 아니라, 이 시간대에 평소 얼마나 늦는지도 보여줍니다.

## 기능

- 경의중앙선 전 구간(문산~지평, 지선 포함)의 열차 위치를 수집하고 이력을 저장합니다.
- 역, 방향, 행선지별로 시간표 대비 지연을 판정합니다.
- 요일과 시간대별 지연 확률, 역 사이 구간 지체 시간을 계산합니다.
- 역, 방향, 행선지를 구독하면 지연될 때 웹 푸시를 보냅니다. 회원가입은 없습니다.

## 기술 스택

Java 25, Spring Boot 4.1, Gradle(Kotlin DSL), MySQL 8.4, Flyway, Spring Modulith, Micrometer, Prometheus, Grafana, Docker Compose, GitHub Actions
